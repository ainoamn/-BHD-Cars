## ملخص النشر

- صفحة `/sell` بمسارات مجمّعة ومساعد اقتراح المسار.
- 12 مسار عرض (بما فيها زيوت ومواد تشغيل) بمعالج خطوة بخطوة.
- مصطلحات BHD أدق، مؤشر جاهزية العرض، وصياغة عنوان/تفاصيل بالذكاء الاصطناعي.
- سيارات للبيع تبقى مسارين منفصلين: جاهزة / حادث معلن.

## التحقق بعد النشر

- [ ] `/sell` يعرض ثلاث مجموعات مسارات + صندوق المساعد
- [ ] اقتراح مسار من جملة مثل «تأجير بيك أب شهري» يفتح `/sell/cars-rent`
- [ ] `/sell/parts` يبدأ بنظام القطعة وليس قائمة متشعّبة
- [ ] `/sell/consumables` يقبل زيت/فلتر وينشر طلبًا من نوع `part`
- [ ] في أي مسار: مؤشر الجاهزية يرتفع مع تعبئة الحقول الإلزامية
- [ ] عنوان/تفاصيل: أزرار المساعد تملأ الحقل حتى بدون مفتاح AI (قالب)
- [ ] `/sell/cars-sale` → جاهزة يفتح `/sell/ready` ومعالج السيارة الكامل
- [ ] بعد النشر يظهر رقم مرجعي في `/requests`

## ملاحظات تشغيل

- لا تُرفع مرفقات PDF المرجعية إلى المستودع؛ الفكرة مُعاد بناؤها في الكود فقط.
