## الهدف

تشغيل لوحة تحكم الموقع بنفس أسلوب BHD R، وفصل لوحات المستخدم/المعرض مع عزل بيانات وصلاحيات موظفين.

## ما دخل

### تحكم الموقع (`/admin`)

- بوابة SSO + قائمة `SITE_ADMIN_EMAILS` / `SITE_ADMIN_SUBS`
- أقسام: سوق، تشغيل، شركاء، منصة، موقع
- إعدادات الموقع فقط في `/admin/settings` (صيانة، تنبيه، صفحات، سوق افتراضي)
- ضوابط إعلانات/مزادات/معارض، طلبات، دعم، باقات، مدفوعات، تفويض — عبر Neon + `/api/admin/[resource]`
- الصيانة والتنبيه يطبَّقان على الموقع العام عبر `SiteRuntime`

### لوحات المستخدم والمعرض

| المسار | الغرض |
|---|---|
| `/portal` | اختيار المساحة (شخصي / منشأة) |
| `/account` | تحكم المستخدم — مركبات وطلبات شخصية |
| `/workspace` | تحكم المعرض/الشركة — مركبات وطلبات المنشأة |
| `/workspace/team` | دعوة موظفين ومنح صلاحيات محددة |

### عزل البيانات

- الشخصي: استعلامات بـ `owner_user_id = session.sub` و`org_id IS NULL`
- المنشأة: استعلامات بـ `org_id` النشط في كوكي `bhd_cars_org` فقط
- العضوية عبر `org_memberships`؛ الدعوة عبر `org_invitations` تُقبل عند تسجيل الدخول بالبريد

### صلاحيات الفريق (scopes)

`listings.read/write` · `requests.read/write` · `team.read/write` · `settings.read/write` · `auctions.*` · `analytics.read` · أو `all`

## جداول Neon الأساسية

`site_settings`, `listing_controls`, `auction_controls`, `dealer_controls`, `service_requests`, `support_tickets`, `platform_*`, `payment_gateways`, `admin_delegates`, `market_controls`, `partner_orgs`, **`orgs`**, **`org_memberships`**, **`org_invitations`**, **`user_listings`**, **`user_requests`**

## متغيرات البيئة المطلوبة (إنتاج)

- `AUTH_SECRET`
- `DATABASE_URL` — سلسلة Neon فقط (بدون بادئة `DATABASE_URL=`)
- `SITE_ADMIN_EMAILS` / `SITE_ADMIN_SUBS`
- `BHD_OAUTH_*` لدخول الهوية

محليًا: `SITE_ADMIN_DEV_OPEN=1` لمعاينة اللوحات بدون SSO.
