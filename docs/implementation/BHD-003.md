# BHD-003 — مسارات العرض والمساعد الذكي

## الهدف

إعادة بناء إضافة العرض على `/sell` بأسلوب BHD: مسارات مجمّعة، مصطلحات دقيقة، إدخال خطوة بخطوة، ومساعد ذكاء اصطناعي — دون محاكاة قوائم أو نصوص مواقع أخرى.

## المسارات

| المسار | الرابط | النمط |
|---|---|---|
| سيارات للبيع | `/sell/cars-sale` | فرعي: جاهزة `/sell/ready` · حادث `/sell/accident` |
| تأجير مركبات | `/sell/cars-rent` | معالج عام |
| مركبات للتفكيك | `/sell/scrap` | معالج عام |
| دراجات نارية وملحقاتها | `/sell/motorcycle` | معالج عام |
| معدات ثقيلة | `/sell/heavy` | معالج عام |
| شاحنات وحافلات ومقطورات | `/sell/trucks` | معالج عام |
| قوارب ومركبات بحرية | `/sell/boats` | معالج عام |
| أرقام لوحات مميزة | `/sell/plates` | معالج عام |
| إطارات وعجلات | `/sell/tires` | معالج عام |
| قطع غيار المركبات | `/sell/parts` | أنظمة قطع بدل قوائم متشعّبة |
| زيوت ومواد تشغيل | `/sell/consumables` | مسار جديد |
| إضافات وتجهيزات | `/sell/accessories` | معالج عام |

المجموعات في الواجهة: **مركبات ومعدات** · **قطع وتجهيزات** · **أرقام مميزة**.

## الملفات الأساسية

- `src/lib/listing-sections.ts` — كتالوج المسارات والحقول
- `src/lib/site-menus.ts` — قوائم الرأس/التذييل/الصفحة الرئيسية من التصنيفات الجديدة
- `src/components/shell.tsx` — شريط التنقّل والتذييل
- `src/components/home-view.tsx` — بطاقات «ماذا تريد اليوم؟»
- `src/components/section-wizard.tsx` — معالج عام + جاهزية العرض %
- `src/components/sell-wizard.tsx` — سيارة جاهزة (حقول كاملة + AI)
- `src/components/market-boards.tsx` — لوحات التأجير/القطع/التفكيك/اللوحات + روابط أضف عرضًا
- `src/app/sell/page.tsx` — اختيار المسار + مساعد الاقتراح
- `src/app/sell/[section]/page.tsx` — توجيه المسار
- `src/lib/ai/listing-assist.ts` — route / title / description
- `src/app/api/ai/listing-assist/route.ts` — واجهة المساعد
- `src/lib/ai/listing-description.ts` — وصف سيارة جاهزة بأساليب BHD
- `src/lib/sell-options.ts` — مصطلحات مواصفات/دفع/أساليب صياغة

## المساعد الذكي

| الإجراء | الاستخدام |
|---|---|
| `route` | جملة حرة → اقتراح `sectionId` |
| `title` | صياغة عنوان العرض من البيانات |
| `description` | تفاصيل بأساليب: ودّي / هادئ / مختصر |

المفاتيح اختيارية: `OPENAI_API_KEY` أو `GROQ_API_KEY`. عند غيابها يعمل قالب آمن.

## مبادئ المصطلحات

- «مصدر المواصفات» بدل عبارات غامضة أو منسوخة
- «عنوان العرض» و«تفاصيل العرض» بدل تسميات إعلان عامة
- «مركبات للتفكيك» بدل سكراب فضفاض
- «نقدًا / بالأقساط» بدل كاش العامية في واجهة الدفع
- أنظمة قطع: محرك وناقل، فرامل، هيكل، كهرباء… بدل شجرة فئات لا نهائية

## الذيل المشترك لكل مسار (ما عدا cars-sale)

صور → محافظة → ولاية → منطقة → عنوان → تفاصيل (+AI) → سعر → أسلوب سداد → رقم تواصل → نشر

الطلبات تُحفظ عبر `useStore().addRequest` مع `kind` المناسب (`sell` · `rental` · `scrap` · `part` · `plate`).
