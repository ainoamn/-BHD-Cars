# BHD Cars

منصة سيارات للشراء والبيع والمزاد، مع تثمين وتمويل وتأمين وفحص واستيراد وتأجير وقطع غيار.

## التشغيل المحلي

```bash
npm install
npm run dev
```

يفتح على [http://localhost:3010](http://localhost:3010).

## البناء

```bash
npm run build
npm start
```

## المكدس

Next.js 15 · React 19 · TypeScript · Tailwind CSS 4
